# NovaCart — Premium All-in-One E-Commerce Marketplace

A production-quality e-commerce frontend built with **React**, **Vite**, **TypeScript**, **Tailwind CSS**, and **Motion for React**.

## Features

- **Premium Brand Identity**: Deep navy/slate hero aesthetic with vibrant electric indigo and cyan gradient accents, paired with clean high-visibility shopping catalogs.
- **Realistic 25+ Product Catalog**: Spanning Sneakers, Men's & Women's Fashion, Flagship Mobiles & Audio, Smart Living Gadgets, Clean Beauty, and Scandinavian Home Decor with realistic Indian Rupee (₹) pricing, ratings, discounts, and real photography.
- **Interactive Homepage**:
  - Slim announcement bar featuring shipping offers
  - Sticky glass navbar with live search and dynamic counter badges
  - Dark hero showcase with floating product cards and motion aesthetics
  - Horizontal photo category rail with direct department links
  - Trending Now, Curated Best Sellers, Just Dropped arrivals, Editorial Lookbook, and Verified Buyer reviews
- **Shop & Category Filtering**: Multi-faceted sidebar with category selection, price range sliders, brand multi-select checkboxes, rating filters, stock toggles, and sorting by popularity, price, rating, and recency.
- **Product Details Page**: Multi-angle image gallery with thumbnail navigation, color swatch selections, shoe/garment size pickers, quantity controls, Add to Cart, 1-Click Buy Now, guarantee badges, and related recommendations.
- **Quick View Dialog**: Preview products anywhere in a modal without leaving the catalog.
- **Slide-Over Mini Cart & Dedicated Cart Page**: Real-time quantity steppers, item deletion, coupon code engine (`NOVA15`), subtotal, discount, and shipping calculations.
- **Wishlist**: Instant heart toggle with persistent state and 1-click Move-to-Cart.
- **Checkout Wizard**: Step-by-step shipping address form, payment method radio options (UPI, Cards, COD), demo sandbox disclaimer, and order confirmation receipt (`#NC720458`).
- **Account & Orders**: Customer profile, tracked demo shipments, addresses, and saved payment methods.
- **Mobile Bottom Navigation**: Native-app styled bottom bar for touch devices.

## Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Motion for React (`motion`)
- **Icons**: Lucide React
- **Routing**: React Router v6
- **State Management**: React Context + `localStorage` persistence

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
